# BAR OS: 複数端末同期と正確な利益計算
現行アプリはlocalStorageを使用するデモです。iPhone/iPad/PCでの共有はまだ有効ではありません。
本番化の推奨: Supabase Auth + PostgreSQL + Row Level Security + Realtime、Vercel HTTPS。
1. 非公開のSupabaseプロジェクトを作成。
2. supabase/schema.sql をSQL Editorで実行（初期状態ではRLSで全アクセスを拒否）。
3. メール等の安全なログイン認証とshop_membersによる3権限のRLSポリシーを実装。
4. 全CRUDをlocalStorageからSupabaseへ移行し、Realtime購読と衝突対策を実装。
5. 決済確定はサーバーのトランザクションで行い、決済の二重登録を防止。
6. 監査ログはDB側のトリガー/権限で改ざん防止。
7. 共有と認証を端末間でテスト後に本番切替。

## 正確な計算の定義
税込売上=確定した決済の合計（返金はマイナス計上）。
商品原価=会計時点で確定した注文行の単価原価×数量の合計（原価履歴を固定）。
人件費=各スタッフの勤務時間×その勤務時点の時給＋割増・交通費・法定福利費等。
店舗利益（簡易）=税抜売上−税抜原価−人件費−その他経費。
消費税、支払方法別手数料、廃棄ロス、値引き、家賃、光熱費を含めない数字を「正確な純利益」と呼ばない。
担当スタッフ別売上は会計処理者の売上であり、個人が生み出した利益とは限らない。
複数人で接客した売上の配賦ルールが必要。

現行の価格・在庫デモ表示と会計ロジックは会計ソフト相当ではありません。
