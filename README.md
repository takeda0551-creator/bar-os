# BAR OS

CHANCE向けバー運営OSのMVP。

## 実装済み
- 4桁スタッフPINログイン（デモ）
- 席管理 / 新規来店
- 注文追加
- 飲み放題残り時間
- 会計 / 席解放
- サービス処理
- 重要操作ログ / 未確認件数
- オーナー確認処理
- 在庫残量画面
- 勤怠（出勤 / 退勤）
- iPhone / iPad / PC対応
- LocalStorageでデモ状態を保持
- CHANCEメニュー初期データ

## ローカル起動
npm install
npm run dev

## 次の本番化
Supabase接続、スタッフ権限、DB永続化、監査ログ改ざん防止、Web Push通知、レジ締め、顧客・ボトルキープ、売上/粗利/人件費分析、AI分析、Vercel公開。
